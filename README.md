## ⚡ 2. Các Tính Năng Luyện Phản Xạ Chủ Động (Active Fluency Engine)

1. **🖼️ Hình Nền Sách Giấy Tự Động trên macOS (Retina 1:1 Vector Wallpaper)**  
   Tự động kết xuất trang sách sắc nét lên màn hình chính macOS (hỗ trợ 3 chất liệu giấy: *Kem Sách Cổ Điển*, *Trắng Sách Giáo Khoa*, *Chế Độ Tối E-Ink*).
2. **🎙️ Phòng Luyện Phát Âm & Đóng Vai Bản Xứ (Shadowing & Roleplay Coach)**  
   Thu âm giọng nói trực tiếp qua Microphone, nhận diện giọng nói tiếng Đức bản địa (`SFSpeechRecognizer de-DE`) và chấm điểm độ chính xác từng từ kèm gợi ý sửa lỗi.
3. **🧠 Thuật Toán Lặp Lại Ngắt Quãng Thông Minh (Smart Spaced Repetition - SRS) & Active Recall**  
   Chấm mức độ phản xạ (`🔥 Chưa nhớ 2h`, `🤔 Tạm nhớ 3 ngày`, `⚡ Phản xạ ngay 14+ ngày`) và chế độ **Thử thách Phản xạ Chủ động** (ẩn câu tiếng Đức trên hình nền để tự bật ra câu nói trước khi xem đáp án).
4. **🎧 Đài Phát Thanh Phản Xạ Pimsleur 4 Nhịp (Hands-Free Radio Mode)**  
   Tự động đọc câu hỏi ngữ cảnh tiếng Việt → Dừng nhịp chờ học viên tự bật ra câu tiếng Đức → Phát giọng chuẩn Neural TTS `de-DE-KatjaNeural` / `ConradNeural` → Đọc câu đối đáp lượt 2.
5. **⌨️ Phím Tắt Toàn Cục `⌥ Option + Space` & Spotlight Tra Cứu Tức Thì**  
   Bấm `⌥ Option + Space` ở bất kỳ ứng dụng nào trên Mac để nghe phát âm câu hiện tại ngay lập tức, hoặc gõ từ khóa tình huống (vd: *bác sĩ*, *tàu trễ*, *khẩn cấp*) trên thanh Menu Bar để nhảy tới mẫu câu cần dùng.
6. **📱 Đồng Bộ Máy Đọc Sách Kindle Paperwhite 5 (E-Ink 1236×1648)**  
   Giao diện trình duyệt E-Ink siêu nhẹ (`/kindle`) chống nháy màn hình, tự động lưu trữ ngoại tuyến và xoay vòng mẫu câu trực tiếp trên bàn làm việc.

## 🚀 3. Hướng Dẫn Cài Đặt & Khởi Chạy (macOS)

```bash
# 1. Cài đặt thư viện
npm install

# 2. Khởi chạy máy chủ LinguaWall (Cổng 3456)
npm start

# 3. Cài đặt Ứng dụng macOS Native & Thanh Menu Bar tự khởi động
npm run install:app
```

- **Giao diện Quản lý & Học tập:** Mở trình duyệt tại `http://localhost:3456`
- **Giao diện Kindle Paperwhite 5:** Mở trình duyệt Kindle tại `http://<IP-LAN-CUA-MAC>:3456/kindle`
- **Xuất lại Bộ Sách In A5 DMF (5 quyển PDF):**
  ```bash
  ./bin/generate-dmf-print-book data/sentences.json generated/DMF_Print_Books
  ```
